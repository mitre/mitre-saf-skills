# Guard Rail Enforcement

Throughout the session, use these checks to stay focused on the current epic and avoid scope creep:

| Before... | Ask... |
|-----------|--------|
| Diving into a fix | Is this critical for current epic, or backlog it? |
| Adding a feature | Is this in scope, or scope creep? |
| Researching deeply | Is this knowledge needed now, or defer? |
| Refactoring | Does this block current epic, or "nice to have"? |

Use the recovery file's scope guard rails and key decisions as the reference for these checks.
