# Docusaurus Documentation Conventions

## Directory Structure

```
my-project/
├── docusaurus.config.js     # Main configuration
├── sidebars.js              # Sidebar definitions
├── static/img/              # Static assets
├── src/
│   ├── components/          # React components (usable in MDX)
│   ├── css/custom.css       # Custom styles
│   └── pages/               # Standalone pages (not in docs sidebar)
├── docs/                    # Documentation MD/MDX files
│   ├── intro.md
│   └── tutorial-basics/
│       └── _category_.json  # Category metadata
├── blog/                    # Blog posts
└── versions.json            # Doc versions list
```

Number prefixes control sidebar ordering: `01-Intro.md`, `02-Getting-Started/`.

## Configuration (`docusaurus.config.js`)

```javascript
export default {
  title: 'My Project',
  url: 'https://myproject.dev',
  baseUrl: '/',
  presets: [
    ['@docusaurus/preset-classic', {
      docs: {
        sidebarPath: './sidebars.js',
        editUrl: 'https://github.com/org/repo/edit/main/',
      },
      theme: { customCss: './src/css/custom.css' },
    }],
  ],
  themeConfig: {
    navbar: {
      title: 'My Project',
      items: [
        { type: 'docSidebar', sidebarId: 'main', label: 'Docs' },
        { type: 'docsVersionDropdown', position: 'right' },
      ],
    },
  },
};
```

### Sidebar (`sidebars.js`)

```javascript
export default {
  main: [
    'intro',
    {
      type: 'category',
      label: 'Getting Started',
      items: ['getting-started/install', 'getting-started/config'],
    },
    { type: 'autogenerated', dirName: 'api' },
  ],
};
```

Use `_category_.json` for autogenerated sidebar metadata:
```json
{ "label": "Tutorial", "position": 2, "collapsed": false }
```

## MDX Syntax

Use React components inside markdown (files must be `.mdx` or have `format: 'mdx'` configured):

```mdx
import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

<Tabs>
  <TabItem value="npm" label="npm">npm install pkg</TabItem>
  <TabItem value="yarn" label="Yarn">yarn add pkg</TabItem>
</Tabs>
```

**Admonitions:**
```markdown
:::note
Informational.
:::

:::tip
Helpful advice.
:::

:::warning
Be careful.
:::

:::danger
Critical warning.
:::

:::info[Custom Title]
With custom title.
:::
```

**Code blocks with highlighting:**
````markdown
```javascript title="src/index.js" {3-5}
function greet(name) {
  // highlight-next-line
  return `Hello, ${name}!`;
}
```
````

## Frontmatter

```yaml
---
id: my-doc
title: My Document
description: Short summary for SEO
sidebar_position: 3
sidebar_label: Short Label
slug: /custom-url
tags: [getting-started]
draft: true
---
```

## Versioning

```bash
npx docusaurus docs:version 1.0.0
```

Creates `versioned_docs/version-1.0.0/` snapshot. `docs/` becomes "next" (unreleased).

## Commands

```bash
npm run start     # Dev server (localhost:3000)
npm run build     # Production build to build/
npm run serve     # Serve production build
npm run clear     # Clear cache
```

## Common Gotchas

| Issue | Fix |
|---|---|
| MDX parse errors from `<` or `{` | Escape: `\<`, `\{`, or wrap in backticks |
| Broken links fail build | Fix all links or set `onBrokenLinks: 'warn'` |
| `.md` with JSX fails | Rename to `.mdx` |
| Imports need blank line before markdown | MDX parser requirement |
| `static/` assets need absolute paths | `/img/photo.png` not `../img/photo.png` |
| Sidebar changes not hot-reloaded | Restart dev server |
